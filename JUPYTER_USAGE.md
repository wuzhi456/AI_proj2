# Using the Jupyter Notebook for Training

## Overview

This project uses **Jupyter Notebook** as the primary interface for training and evaluating the neural network model.

## Updated Model Architecture

The neural network has been simplified:

- ✅ **No Dropout**: Removed for simpler architecture
- ✅ **No BatchNorm**: Removed batch normalization layers
- ✅ **Softmax Output**: Changed from Sigmoid to Softmax activation
- ✅ **2 Output Neurons**: For binary classification with Softmax

**Architecture**:
```
Input (14 features)
    ↓
Linear(14 → 128) → ReLU
    ↓
Linear(128 → 64) → ReLU
    ↓
Linear(64 → 32) → ReLU
    ↓
Linear(32 → 2) → Softmax
```

## How to Use

### 1. Start Jupyter Notebook

```bash
jupyter notebook
```

### 2. Open the Training Notebook

Open `training_notebook.ipynb` in the Jupyter interface.

### 3. Run All Cells

Execute cells sequentially or use "Run All" from the Cell menu.

The notebook will:
- Load and visualize data
- Preprocess features
- Build the neural network (simplified architecture)
- Train for 50 epochs
- Display training curves
- Show confusion matrix
- Generate test predictions
- Save predictions to `testlabel.txt`

## What the Notebook Does

### Data Exploration
- Loads training and test data
- Visualizes label distribution
- Shows data statistics

### Model Training
- Creates simplified ANN (no BatchNorm, no Dropout)
- Uses Softmax activation for output
- Trains with CrossEntropyLoss
- Displays epoch-by-epoch progress

### Evaluation
- Shows training/validation curves
- Displays confusion matrix
- Prints classification report
- Calculates ROC-AUC score

### Predictions
- Generates predictions on test set
- Saves to `testlabel.txt`
- Shows prediction distribution

## Model Changes

### What Was Removed
- ❌ BatchNorm1d layers
- ❌ Dropout layers

### What Was Changed
- ✏️ Output activation: Sigmoid → **Softmax**
- ✏️ Output neurons: 1 → **2** (for Softmax)
- ✏️ Loss function: BCELoss → **CrossEntropyLoss**

### What Stayed the Same
- ✅ 3 hidden layers [128, 64, 32]
- ✅ ReLU activation in hidden layers
- ✅ Adam optimizer
- ✅ 50 training epochs
- ✅ Batch size 128

## No More Python Scripts

The `main.py` and `generate_figures.py` scripts have been removed. All functionality is now in the **Jupyter notebook**.
